Getting started

Opening a photo

There are four ways to get a photo into SnapEx:

  • Drag and drop a photo anywhere onto the page.
  • Click the drop area on the home page to pick a file from your device. On a phone this opens your photo library.
  • Paste an image you've copied, with Ctrl+V or ⌘V.
  • Load from URL: switch to that tab and enter the full address of an image.

To explore without a photo of your own, choose Try a sample photo. It comes with made-up camera details and a GPS location so you can see every panel.

Features

Metadata viewer

The panel at the top reads like a camera's info screen: shutter speed, aperture, ISO, focal length, camera, lens and the time the photo was taken. Below it, every tag in the file is listed and grouped by where it is stored: Image & camera, Capture settings, Location, Captions & rights (IPTC), Extended metadata (XMP) and Color profile (ICC). Use the filter box to find a tag by name or value, such as lens or 2024.

Editing metadata

  1. Open a JPEG and choose Edit metadata.
  2. Change the camera make or model, lens, date taken, artist, copyright, description or software. Leave a field empty to delete it.
  3. Tick Remove GPS location or Remove camera and lens serial numbers to drop those details.
  4. Choose Apply changes. SnapEx makes an edited copy and shows its metadata so you can check it.
  5. Choose Download copy to save it. Back to original undoes everything.

Dates use the EXIF format YYYY:MM:DD HH:MM:SS, for example 2026:03:14 06:42:10. EXIF text fields only hold plain ASCII characters, so accented letters are replaced with "?".

Location map

When a photo has GPS coordinates, SnapEx plots them on an OpenStreetMap map and shows latitude, longitude and altitude. The map tiles are loaded from OpenStreetMap, which receives the rough area being viewed but never the photo itself.

Embedded thumbnail

Many cameras and phones store a small preview image inside the photo. SnapEx shows it so you can check that it matches. This matters because some editing apps crop or retouch the main image but leave the old thumbnail behind. For JPEG files you can download the thumbnail, rebuild it from the current photo, or remove it.

Privacy check

Each photo gets an overall rating and a list of what it reveals:

  • High: GPS location, which shows exactly where the photo was taken.
  • Medium: serial numbers, owner or artist names, the exact date and time, unique image IDs and embedded thumbnails. These can identify you or link photos together.
  • Low: camera and lens models and the software used. These are rarely sensitive on their own.

Removing metadata

Remove metadata clears EXIF, GPS, IPTC, XMP and comments in one step. JPEG and PNG files are cleaned without re-compressing the picture, so quality is unchanged. If the photo was taken sideways, SnapEx keeps only the rotation flag so it still displays upright.

Leave Keep color profile when removing ticked to keep the ICC color profile. A profile says nothing about you and keeps colors accurate, especially for wide-gamut photos from newer phones. Untick it for the smallest possible file. WebP files are re-encoded at high quality, because their metadata can't be removed in place.

Exporting metadata

Copy JSON copies all tags to your clipboard and Download JSON saves them as a file, which is useful for records or for comparing photos.

Troubleshooting

"No metadata in this file"

Many images genuinely have none. Screenshots, images saved from social networks and messaging apps, and pictures exported "for web" are usually stripped before you get them. Try the original file straight from the camera or phone instead.

The map doesn't appear

The photo needs GPS data; check the Location group for coordinates. If they are there but the map is blank, an ad blocker or network filter may be blocking OpenStreetMap. The Open in OpenStreetMap link still works.

Load from URL fails

Many websites don't allow other sites to read their images directly. Save the image to your device and open it with Upload file instead.

Edit metadata is greyed out

Editing works on JPEG files only. You can still view metadata for every supported format, and remove it from PNG and WebP files.

Large files are slow

Photos over about 20 MB, especially RAW files, can take a few seconds to read on older phones. Close other tabs or use a computer for very large files.

The preview says the format can't be shown

Some browsers can't display HEIC or RAW images. SnapEx still reads all of their metadata; only the preview is missing.

Privacy and security

  • Processed on your device. Photos are read and rewritten in your browser and never sent anywhere.
  • No accounts and no tracking. SnapEx uses no analytics, ads or tracking cookies.
  • Open source. All the code is on GitHub for anyone to check.
